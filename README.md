# AI-Enabled-Water-Well-Predictor-Major-Project

### Major Project | College Academic Project

A web-based decision support system that helps users decide the suitability of constructing a water well at any selected location in India.  
The system provides predictions on well suitability, expected water-bearing zones, discharge, recommended drilling technique, and groundwater quality.

**Inspired by NAQUIM data of Central Ground Water Board (CGWB)**

## 🎯 Project Objectives

On a user-selected point, the system predicts:

1. Whether the area is suitable for water well construction
2. Expected depths of water-bearing zones
3. Expected discharge of the well
4. Most suitable drilling technique
5. Expected quality of groundwater
6. Other relevant hydrogeological information

The application also includes a structured user feedback system.
